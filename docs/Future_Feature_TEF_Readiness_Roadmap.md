# Future Feature: TEF Readiness Roadmap

Date: 2026-08-18
Status: Future feature / product concept

## Idea

Add a learner-facing roadmap that helps users understand:

- where they are now
- what their next goal is
- which skills they still need to strengthen
- how their mission performance connects to broader A1 / A2 / B1 readiness

The goal is to give TEF Canada learners a clear sense of progress and a reason to keep practicing.

## Product Principle

French Quest should not reduce progress to only:

- number of completed missions
- raw score
- XP-style gamification

The roadmap should combine mission progress, skill performance, weak spots, review results, and readiness indicators.

## Important Accuracy Rule

Do not claim that a specific French Quest score automatically equals an official CEFR or TEF level.

For example, avoid promises such as:

> 80 points = A2
> 120 points = B1

Until French Quest has enough calibrated content and user-performance data, readiness labels should be directional rather than guarantees.

Possible labels:

- A1 Foundation
- A2 Building
- A2 Ready
- B1 Building
- B1 Ready

These should communicate learning progress, not official TEF certification.

## Possible Roadmap Structure

### 1. Mission Progress

Example:

- Coffee Shop — Complete
- Grocery Store — Locked / Coming Soon
- Banking — Locked / Coming Soon

### 2. Skill Progress

Possible skill dimensions:

- Vocabulary
- Situation comprehension
- Best Response
- Mini Reading
- Later: listening comprehension

Example UI concept:

- Vocabulary: 80%
- Situation: 72%
- Best Response: 68%
- Reading: 60%

The important part is not the percentage itself, but the interpretation:

> Reading is currently your weakest area. Complete more reading tasks and review your weak spots.

### 3. Readiness Stage

Example progression:

#### A1 Foundation

Learner can:

- understand common everyday vocabulary
- recognize basic service expressions
- identify simple Yes / No and either-or questions

#### A2 Building

Possible future indicators:

- completed several real-life missions
- stable performance across Situation / Best Response / Reading
- reviewed weak spots
- can identify keywords and simple communicative intent

#### A2 Ready

Possible future indicators:

- stable performance across multiple missions
- can understand opening hours, notices, payment information, service interactions, and common instructions
- retake / review performance shows fewer recurring weak spots

#### B1 Building

Learner begins handling:

- longer situational information
- stronger distractors
- simple inference
- questions that cannot be solved only by direct vocabulary matching

#### B1 Ready

Possible future indicators:

- stable performance across diverse real-life contexts
- can identify main idea, details, intent, and practical implications
- can handle more complex authentic-style information

## Relationship to Weak Spots / Review Mode

Current Weak Spots and Review Mode operate at the question level.

Future Roadmap can elevate this into a skill-level view.

Example:

Question-level:

> You missed CS023.

Skill-level:

> You often miss restriction words such as seulement.

Roadmap-level:

> Reading: A2 Building — restriction and notice questions need more practice.

This would connect existing Review Mode to a larger learning system rather than treating wrong answers as isolated mistakes.

## Short-Term UI Teaser

Before the full readiness logic exists, French Quest could display a locked / Coming Soon Roadmap UI.

Possible copy:

### Your TEF Roadmap

- A1 Foundation — Complete
- A2 Building — Coming Soon
- B1 Building — Locked

or:

> Track your mission progress, skill strengths, weak spots, and A2 → B1 readiness.

The teaser can communicate the future value of French Quest without pretending the current product can already diagnose CEFR / TEF readiness accurately.

## Why This Matters

The roadmap gives learners a clearer answer to:

> Why should I complete another mission?

Instead of only unlocking more content, learners can feel that each mission contributes toward a visible capability goal.

This supports the core French Quest positioning:

> Real Canadian life mission + TEF-style comprehension + teacher-style Traditional Chinese support + metacognitive learning design.

## Timing

Short term:

- keep as a documented future feature
- optionally create a locked / Coming Soon UI teaser

Later, after more missions exist:

- define skill-level metrics
- define readiness criteria
- connect Review Mode / weak spots to skill progress
- validate score thresholds using enough content and learner data

Do not build official-looking A2 / B1 score equivalencies prematurely.
